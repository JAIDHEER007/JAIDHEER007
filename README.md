# 🚀 Featured Projects

### 🤖 Agentic Workflow Engine with Human Approval `In Progress`
`Python` · `FastAPI` · `React` · `PostgreSQL` · `Redis` · `LLM`

A durable execution engine where an LLM decomposes a request into a step DAG, a human approves or edits each step, and a worker pool executes against real third-party APIs. Survives worker crashes mid-run with zero duplicate side effects using idempotency keys and pre-commit state persistence. Irreversible steps are handled with saga-based compensation rather than 2PC, since there's no coordinator across external systems. Full append-only event log powers plan replay and per-run cost tracking.

### 🗳️ Raft Consensus Implementation
`Python` · `Flask` · `WebSockets` · `Virtual Machines`

Distributed consensus simulator modeling leader election, log replication, and fault recovery across 5–15 node clusters. Achieved 100% correctness under network partitions, node crashes, and leader re-elections.

### 🏦 Distributed Banking System — Paxos & Two-Phase Commit
`Python` · `Distributed Transactions`

Cross-shard transactional banking system implementing Paxos for intra-shard consensus and 2PC for atomic cross-shard transfers, with coordinator failure handling and locking to preserve consistency.

### 📝 Collaborative Text Editor (Google Docs Replica)
`ReactJS` · `Node.js` · `Socket.IO` · `WebRTC` · `MongoDB` · `IndexedDB`

Real-time multi-user editor with offline edit support via IndexedDB and conflict reconciliation on reconnect. Granular RBAC permissions with 350–500ms data retrieval times through optimized database access patterns.

### 🎨 Picaso — Image Generation & Sharing Platform
`Django` · `AWS S3/RDS` · `OpenAI` · `OAuth 2.0` · `PostgreSQL`

Multi-user image generation platform with Google OAuth 2.0 authentication, generative image APIs, S3-backed storage, and metadata management in Postgres on AWS RDS.
